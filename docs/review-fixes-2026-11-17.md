| R12 转盘非法类型 | 写事务前检查元素及 label 类型，非法元素返回 422 | 数值、布尔、null、数组及非法对象逐项测试，原清单不变 |

| R14 连续回车跳步 | 拦截引导中的重复 Enter/空格；包括按钮焦点下的浏览器原生连续点击 | DOM 单测及真实键盘连续 keydown，确认只前进一次 |

R08 采用“下一次新练习”的范围，是本次明确的行为约定；打开旧练习不会消费待关联项。中途明确放弃未确认开始请求后，可能已提交的练习仍需在历史中核查，沿用原来的请求幂等及退出提示。

## 2. 其他确认问题

- **注册与登录**：注册在密码哈希前限制频率；未知用户名也执行密码哈希校验。注册冲突仍保留原有 409 语义，不声称已经完全消除用户名推断。
- **兑换码生成**：直接依赖数据库唯一约束插入，冲突有限重试 10 次，去除逐个全表读取；非碰撞错误继续抛出。
- **可访问性交互**：评分局部更新并保留选中按钮焦点；反馈选择恢复原操作焦点。主题变化保留编辑焦点/选区及登录表单输入；后台请求结束时重新检查用户是否正在编辑。
- **HTTP 静态资源**：gzip、内容 ETag、Last-Modified、304、HEAD、Vary 配套实现，API 保持 no-store，CSP 显式 object-src 'none'。SW 使用内容 ETag 校验；单独 If-Modified-Since 不返回 304，以免删除资产后最大修改时间未增加造成错误命中。
- **缓存与导入**：AI cache_get 为纯查询并检查 24 小时有效期；清理移至启动及小时维护、增加时间表达式索引。导入在同一写事务内按账号/时间范围读取一次候选，内存去重集合受本批条目限制，保留数据版本与按账号清缓存的触发器。
- **SW 版本成本**：静态内容表示缓存；扫描完整路径/大小/mtime_ns 清单，变化时才读取全部内容重新哈希；覆盖等长修改和删除。正常文件扫描避免重复 resolve/stat；不递归目录链接和 Windows junction。
- **维护与文档**：清除已确认的无用时间函数、参数及旧解析函数；README 补全 37 个方法/路由组合、Pro 边界、转盘规则、导入字段、环境参数和测试命令；移除 API 头部过时的订阅路由注释。
- **CI**：新增 GitHub Actions 配置，运行 Python 和 Node 回归；Windows/Linux、Python 3.10/3.13、Node 24。此处只完成配置，未推送或宣称远端 CI 已通过。

## 3. 隔离性能复测

命令：`python -B tests/benchmark_review.py`。数据每组 5000 条，原因文本各不相同，分别使用每条不同秒和全部相同时间。未更改 SQLite 持久性模式、未关闭触发器。

| 场景 | 修复后本机耗时 |
|---|---:|
| 不同时间，首次导入 | 1.2605 秒 |
| 不同时间，全部重复导入 | 0.0470 秒 |
| 相同时间，首次导入 | 1.2126 秒 |
| 相同时间，全部重复导入 | 0.0487 秒 |
| SW 已缓存表示，连续 20 次平均 | 1.572 毫秒 |

基线复核中，重复导入为 0.8291 / 2.2834 秒。本轮实测显示重复导入明显改善，但两次测量非同一时刻、也不是生产压测，不外推固定倍数或线上 SLA。SW 这里测的是表示生成函数，基线报告为完整 HTTP 请求耗时，不能直接相除。

性能测量时 app.js 为 114,537 字节，gzip level 6 后 33,620 字节；后续少量交互补丁会改变精确字节数。实际响应压缩与解压一致性由 HTTP 测试检查，不能把该值等同于全部首屏网络流量。
