# 智心元流 · 手机端设计调整

范围：手机端界面。所有宽度继续使用单栏和底部五项导航，宽屏也保持手机画幅。

采用 Taste Code 的 Editorial greeting 方向（seed 1240305906），保留原有暖纸底、墨绿、品牌图标和中文字体栈。收到“就是手机端”的补充后，取消桌面双栏和侧边栏方案。没有新增外部图片、字体依赖或演示记录到用户数据库。

## 设计判断

首页要先回答“此刻想表达什么”，再提供情绪入口。原来的插画欢迎卡占据了较多首屏空间，输入区有重复标题，字体与图标说明偏小，彩色底、颗粒、渐变和阴影让多张卡片争夺注意力。

调整后的产品特征是：暖纸色个人空间、衬线主标题、清晰的自由表达输入区，以及保留表情识别的情绪选择。没有把情绪记录包装成指标仪表盘。

| 部分 | 调整前 | 调整后 |
| --- | --- | --- |
| 首页开头 | 插画横幅，内容向下推 | 直接显示问候、日期、问题和简短说明 |
| 自由表达 | 引导小标题和标题叠加 | 保留一个清晰标题，输入区优先 |
| 首页说明 | 12px | 14px |
| 品牌副标题 | 9px | 11px |
| 登录说明 | 11px | 13px |
| 情绪入口 | 多种浅彩色面板，各自带框 | 同一中性色面板；表情保留语义颜色 |
| 底部导航 | 深绿实心选中项，强阴影 | 浅色选中项，图标与文字共同识别 |
| 练习列表 | 图标色块、装饰编号 | 线性图标、真实时长和练习名称 |
| 页面背景 | 颗粒、渐变 | 纯色暖纸 |
| 现有数据图 | 渐变柱形 | 保留数据与刻度，柱形改为纯色 |

输入仍保留可访问的字段标签、字符计数、隐私提示和原有保存流程。深色模式使用既有暖炭配色；不改变练习、登录、记录、危机资源或 AI 调用逻辑。

## 截图复核

初次复核的三个问题：首屏层级重复、说明字号过小、装饰性颜色与卡片竞争。已经分别通过移除首页插画欢迎框、精简表达标题、提高字号和统一表面处理。

第二次复核发现 390px 首屏的情绪选项尾部接近底部导航，进一步收紧输入区与情绪区之间的间距。底部始终保留安全区和滚动余量，页面最后一项可以滚动至导航上方。

既有登录插画只保留在登录页，属于项目自有品牌素材。没有用照片替代情绪表情或练习引导，也没有添加会干扰输入的入场动画。
