# 自助练习：功能闭环

本模块完成「选练习 → 可选练习前评分 → 分步引导 → 可选练习后评分与反馈 → 保存 → 历史回看」的流程。页面统一使用手机单列布局，大屏也不展开成多列；支持中英文、浅色和深色主题。

## 使用流程

1. 从底部「练习」进入四个练习：回到当下、观察一个念头、给情绪一点空间、做一件小事。也可从已保存的情绪记录进入，编辑中的原因会先保存，再关联练习。
2. 开始前可选择 1–5 的自评，或不评分。点击开始后，服务器创建独立的练习记录。
3. 每个练习有三步。计时器需要主动启动，可暂停，不会自动跳步或自动保存。文字回答可留空，每项最多 500 字。点击下一步先保存，再推进。
4. 点击「保存并稍后继续」保存本页编辑后退出。刷新后从练习足迹继续服务器已确认的进度。浏览器返回也会先尝试保存编辑。
5. 最后可填写练习后评分、感觉变化和备注，全部可以跳过。保存完成后显示中性的记录结果；选择「更难受」会显示支持性提示，并在结果页提供支持资源入口。
6. 可提前结束并保留记录，也可在历史中查看、继续、确认删除或独立导出。删除练习不会删除关联情绪记录；删除或清空情绪记录只解除关联，保留练习。

## 内容与范围

- `backend/app/practices.py` 保存原创中英文短练习文本和内容版本，当前版本为 1。概念参考为 WHO《Doing What Matters in Times of Stress》（2020），本产品不复现该完整项目，也不宣称具有相同疗效。
- 内容尚未完成临床审核，定位为日常自我照顾，不提供诊断或替代专业治疗。前后评分是个人自评，不用于证明治疗效果。
- 练习流程不调用 AI，不将练习回答发送给模型。现有其他 AI 功能的行为不因此改变。
- 创建练习时保存完整双语内容快照和版本。之后修改练习库不会改变旧记录中的引导内容。

## 保存与失败处理

- 每个账号内的 `client_id` 唯一。创建请求响应丢失后，使用同一标识和原始参数重试，不重复创建。
- 更新提交 `request_id` 和 `revision`。服务器使用事务检查版本；紧接着重放同一请求返回已保存结果，旧版本或终态上的新更新返回 409。客户端保留失败请求的原始参数，不自动改变请求标识。
- 409 不会静默覆盖本页输入；用户确认后才能重新打开服务器版本。完成和提前结束后的记录不能继续修改，但可以查看或删除。
- 断网或保存失败时保留当前页面中的文字，并提供重试。无法恢复时可选择「离开此页」，再次确认后丢弃本页未确认内容；这不会撤销服务器可能已经收到的请求，也不会删除记录。恢复连接后需从历史核对。
- 私密草稿仅在内存中；离开或刷新前有未确认变更时触发浏览器的离开提醒（是否显示由浏览器决定）。刷新只能恢复服务器已经确认的内容，不承诺离线编辑。
- 保存步骤和文字，不持久化计时器剩余秒数；重新打开时从当前步骤的完整计时开始，仍需主动启动。
- 登录失效或退出时清除客户端练习状态，迟到的异步响应不能恢复上一账号数据。

## 数据与接口

启动时通过现有数据库初始化机制创建 `practice_sessions` 表及索引，不需要删除或重建数据库。主要字段包括账号、请求标识、练习与内容版本、双语快照、可选情绪记录关联、状态、步骤、前后评分、回答、反馈、开始/结束时间、本地日期、时区和修订号。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/api/practices` | 当前语言的练习库与步骤 |
| POST | `/api/practice-sessions` | 创建练习，支持幂等重试 |
| GET | `/api/practice-sessions` | 账号内历史，支持 `limit`、`cursor`、`entry_id` |
| GET | `/api/practice-sessions/{id}` | 内容快照与记录详情 |
| PATCH | `/api/practice-sessions/{id}` | 保存步骤/回答，完成或提前结束 |
| DELETE | `/api/practice-sessions/{id}` | 删除本账号单条练习 |
| GET | `/api/practice-summary` | 最近 14 个本地自然日汇总 |
| GET | `/api/practice-export` | 导出本账号全部练习为 JSON |

所有记录读写、汇总、关联验证和导出都按登录账号隔离。历史按 ID 倒序游标分页，页面每次加载 10 条。分数未填写时保存 `null`，不会用 0 补齐。

汇总以练习开始时的本地日期归入最近 14 天；今天由查看设备的时区确定。仅已完成且前后均有评分的记录参与前后均值，两侧使用同一分母。提前结束或缺少任一评分的记录不进入配对均值；没有配对记录时返回 `null`。

## 隐私与导出边界

- 与项目现有数据一样，记录位于服务器明文 SQLite 数据库中，按账号隔离，不是端到端加密；服务器或数据库管理员可能访问记录。
- 不将回答或草稿写入 localStorage，service worker 不缓存 API 响应。
- 练习导出是独立的 `zhixinyuanliu-practices.json`。情绪 JSON/CSV 导出不包含练习，本版不支持练习导入。导出文件需要自行保管。
- 「清空情绪记录」保留练习；练习在足迹详情中逐条删除。

## 启动与验证

更新代码后重启 Python 后端，再刷新页面。数据库表会自动创建，前端静态缓存版本随文件内容更新。常规启动：

```sh
python backend/server.py 8000
```

后端测试使用临时数据库，前端基础检查不访问实际账号：

```sh
python -m unittest discover -s tests -v
node tests/run_frontend.mjs
```

真实浏览器测试需要 Playwright 与 Edge，**只在隔离数据目录的测试服务上运行**，会创建测试账号和记录。PowerShell 示例（两个终端）：

```powershell
# 终端 1
$env:TETHER_DATA_DIR = Join-Path $PWD '.cache/practice-preview'
python backend/server.py 8765
```

```powershell
# 终端 2；若 Playwright 不在 Node 默认模块路径，填写实际安装路径
$env:PLAYWRIGHT_MODULE = 'C:/path/to/node_modules/playwright'
$env:TETHER_TEST_URL = 'http://127.0.0.1:8765'
node tests/practice_browser.cjs
```

`EDGE_EXECUTABLE` 可覆盖 Edge 路径。测试覆盖正常闭环、暂停/刷新续练、评分跳过、响应丢失重试、失败退出确认、并发冲突、提前结束、删除、情绪关联、导出及账号隔离，并检查中英文/浅深主题下 320、390、430、1280 像素宽度的布局。截图保存在 `.cache/ui-preview/`。
