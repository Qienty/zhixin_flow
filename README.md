# 智心元流 · 情绪记录与自我调节

移动端优先的情绪表达、记录与自我调节工具。Python 标准库后端 + 原生 JavaScript 前端，无第三方运行依赖。支持登录后自由表达，记录与练习由用户选择，不提供诊断或治疗。

## 启动

需要 Python 3.10+：

```sh
python backend/server.py 8000
```

访问 http://127.0.0.1:8000/。Windows 可运行 `start.bat`，优先使用 PATH 中的 Python；项目不附带 Python 运行时。命令行未指定端口时可用 `PORT` 配置，`HOST` 默认 `127.0.0.1`。

界面语言优先级：**本机选择（localStorage）> 账号里明确设置过 > 浏览器语言 > 中文**。首次访问按浏览器语言决定，非中文浏览器直接进英文界面；用户在账号里点过语言之后，多设备都以账号为准（`lang_set` 标记区分"默认值"和"用户选过"）。

首次启动自动建库并迁移表结构。每个账号的数据相互隔离；升级前应备份 SQLite 数据库。默认位置为 `backend/data/tether.db`，可通过进程环境变量 `TETHER_DATA_DIR` 指定其他数据目录。不要删除数据库来更新应用。

## 自由表达与保存选择

- 登录后的首页可直接写下感受，无需先选择情绪。正文最多 500 字；展开表达空间后可选「只想表达」「帮我理清」「想想下一步」。后两种提供可跳过的本地整理问题，每项最多 160 字；切换方式保留已经写下的答案。这里没有 AI 或真人回复，也不会自动调用模型。
- 默认只在当前页面内存暂留正文和答案，不写入浏览器存储、不自动上传。关闭浮层或切换应用内页面后仍可继续；刷新、关闭网页后不恢复。离开有未保存内容的网页时会请求浏览器提醒。
- 「下载文字到本机」在浏览器内生成 TXT，包含正文、所选整理方式及各方式下已填写的答案，不上传。文件由用户自行保管；清除本页内容不会删除下载文件。
- 登录用户可主动「保存到账号」：先选择情绪、阅读服务器存储说明并确认，才向已有记录接口提交。正文写入原因，整理方式和答案写入备注；不推断情绪强度，也不标记为已完成干预。在记录编辑页可查看、修改或清空补充内容，原有导出、删除机制继续适用。
- 登录后表达空间提供可选的「跨语言表达」：用户选择中文或英文目标语言后，主动点击才会把当前草稿发送给 AI。模型按“沟通意图识别 → 跨文化改写 → 安全校验”的窄流程生成建议表达和必要的语气说明；结果只回到当前页面，用户确认后才可替换原稿，不会自动保存、发送或加入记录。
- 保存失败保留原稿，完整请求及请求标识冻结，重试不重复创建。保存未确认时不能修改请求内容，可先下载；清除本页原稿不撤销可能已到达服务器的记录。
- 登录和注册页面仅提供账号入口，不展示表达空间。表达空间保留在登录后的首页；表达内容仍不会自动上传。
- 保存中遇到会话过期会关闭浮层并恢复可操作的登录页；未保存表达仍暂留内存，可在登录页先下载。重新登录或刷新会重载页面，请先下载需要保留的内容。
- 「清除本次内容并结束」需确认，只移除本页原稿。账号数据、下载文件需在各自位置删除。

跨语言表达接口为 `POST /api/expression/translate`，只接受当前草稿、目标语言和当前整理方式；服务端不持久化转换结果，并沿用 AI 账号并发与冷却限制。未配置 AI 服务时，原有本地表达、下载和账号保存流程仍可使用。

首页同时提供两个入口：「记下此刻」保留原有自由表达；「说给对方听」是独立的跨语言沟通入口，内置 8 个真实场景（延期、拒绝、道歉、求助、冲突复盘、坏消息、争取、边界）。选一个场景、填 1—4 个空（发生了什么 / 原来的时间 / 你希望对方怎么做 / 补充），再选对方身份与语气，接口按场景写出一条可以直接复制发出去的消息，并附一个不同语气的备选版本和最多两条语气提示。接口新增可选字段 `scene`、`tone`（polite/direct/close）、`relation`（professor/manager/client/peer/friend）和 `details`；只传 `text` 时行为与原接口一致。场景与字段清单见 [跨境表达场景](docs/cross-border-scenes.md)。

同一张卡片还提供反向的口径：「对方的话没看懂？」把对方发来的一句贴进来，`POST /api/expression/interpret` 会拆成字面意思、语气档（warm/neutral/tense/harsh/ambiguous）和「可能是」的潜台词，并给 1—2 条可直接复制发送的回复。语气一律标注为推测，不做人格或动机判断；命中临床表述整条拒绝。两个方向都只在用户主动点击时发送，结果不落库。

本轮需求依据、实现范围与验收方式见 [问卷驱动的项目改进](docs/survey-improvements.md)。

## 记录与 14 天边界

- 点情绪只创建内存草稿，先由用户选择「只记录，暂不引导」或「我想试试短引导」，不自动开始引导。跳过、关闭、返回均不写入；完成引导后保存，也可主动保存强度或原因。网络失败时保留草稿，重试使用同一请求标识防止重复记录。草稿不跨刷新保存。
- 首页只在最近 14 个本地自然日中选取强度 ≥4 的记录，按强度、时间、ID 降序取 3 条。没有符合条件的记录时显示最近记录。
- 总结的统计、走势图、归因和 AI 都使用同一 14 天窗口。以查看设备的本地日期确定今天，并与记录发生时的 `local_date` 比较；例如 11 月 16 日计入 11 月 3 日至 16 日。
- 超过 14 天的数据不会删除。记录页支持全历史筛选、严重程度/时间排序、旧记录筛选、编辑、删除和逐条补全。记录页是**翻页制**：每页 8 条，翻页时整页替换并回到本页第一行，列表上下各有一个「上一页 / 第 N / M 页 / 下一页」；不做无限下拉。前端用 `offset` 分页以便显示总页数，服务端同时支持游标分页（默认每页 40 条，供其他场景使用）。
- JSON/CSV 导出包含全部记录。JSON 导入只追加，完全相同的条目跳过，错误文件整批拒绝。每次最多 5000 条、8 MiB；更大的备份需拆分。
- 演示数据先确认再追加 28 条，永不覆盖；演示记录参与统计，建议在测试账号使用。已有未补全记录不会自动清除。
- 顶部可手动刷新；切换页面、从后台返回和网络恢复时更新数据，页面停留期间每分钟检查一次。自动更新会避开正在编辑、保存或分析的操作，保留记录页的当前分页位置。
- 普通请求等待上限为 30 秒，AI 分析为 5 分钟。超时会恢复操作入口并保留当前保存草稿，不自动重发写入请求。AI 可点击「停止等待」；这不会撤销服务器已经收到的操作，也不保证停止模型计费。
- 从情绪引导打开支持资源，关闭资源或按浏览器返回会恢复原引导、步骤与草稿；资源页停留期间暂停引导计时。记录加载失败会在列表内显示重试入口。主动停止 AI 等待保留已有结果，不显示为分析失败。

## 自助练习

底部「练习」页提供四个短练习，支持可选前后评分、分步引导、暂存续练、反馈、历史回看和独立 JSON 导出。可以从情绪记录进入并关联本次练习；清空情绪记录不会清空练习。界面保持手机单列布局。完整流程、接口、保存规则和测试方式见 [自助练习实现说明](docs/practices.md)。

练习的前后评分不只留在练习页：结束后会让「总结」页的本周证据卡过期，下次进入总结时重算。证据卡把这一周的记录（条数、强度 4 以上的条数）与练习（完成次数、有前后评分的次数、平均从几分到几分、其中几次下降）放在一起，并给出与前一周的对照。数字全部由代码聚合，不经过模型，也不构成评估或诊断。

关联只用于下一次成功开始的新练习。开始请求失败或响应丢失时，重试仍使用原请求及关联；成功开始后，后续新练习不再自动关联同一条情绪记录。

## 缓解转盘

登录后可打开转盘，首次访问按当时界面语言创建默认清单。可编辑为 2—12 项，每项最多 24 字，保存到当前账号；之后切换语言不会覆盖已保存的文案。启用系统「减少动态效果」时立即显示抽选结果。它只帮助选择活动，不会自动创建情绪或练习记录。

## AI 与 Pro

AI 是这个产品的核心能力，不是可选插件：跨语言沟通、解读对方的话、Pro 层记录分析都由同一条模型连接提供。配好之后在「我的」页可以看到连接状态和模型名，并点「测试连接」验证一次最小调用（返回模型与耗时）。

Pro 通过兑换码开通，没有订阅或支付。复制 `.env.example` 为 `.env` 并配置兼容服务：

```ini
TETHER_AI_API_KEY=your-key
TETHER_AI_BASE_URL=https://api.deepseek.com/v1
TETHER_AI_MODEL=deepseek-flash
```

供应商矩阵（任何 OpenAI 兼容 `/chat/completions` 都能接）：

| 场景 | Base URL | 说明 |
|---|---|---|
| DeepSeek | `https://api.deepseek.com/v1` | 默认配置，支持 `reasoning_effort` |
| OpenAI | `https://api.openai.com/v1` | 需支持 `response_format: json_object` |
| 自建 / 代理 | 你的地址 | 需兼容上面的 JSON 模式 |
| 本地离线 | `http://127.0.0.1:11434/v1` | Ollama 等本地服务，无网也能演示 |

可选配置：`TETHER_AI_FALLBACK_BASE_URL` / `TETHER_AI_FALLBACK_MODEL` / `TETHER_AI_FALLBACK_API_KEY` 提供备用端点，主用网络失败时自动切换；`TETHER_AI_TIMEOUT`、`TETHER_AI_MAX_TOKENS`、`TETHER_AI_REASONING_EFFORT` 控制超时、输出预算与推理强度；`TETHER_LANGUAGES`（默认 `zh,en`）决定对外可选的目标语言。加一门语言只需要在 `backend/app/pragmatics.py` 的 `LANGUAGES` 里补一条四维配置，并把代码加进这个变量，接口、提示词与前端下拉框都会自动跟随。`POST /api/ai/selftest` 与其它模型调用共用并发和冷却限制（每账号 60 秒一次），避免被当成免费打模型的通道。

打开总结页仅计算统计与读取有效缓存。用户点击「开始分析 / 重新分析」才会调用模型；没配 key、样本不足或请求失败时保留规则统计。模型会收到聚合结果及最多 60 条记录摘要（原因最多 40 字、备注最多 60 字）。

跨语言表达是独立的显式动作，不要求 Pro 记录分析，也不改变默认“不自动上传”的表达流程。它的模型输出固定为结构化 JSON，包含转换文本、沟通意图和最多两条语气说明；临床表述会被拒绝显示。当前实现用于验证跨境语言与文化表达场景，正式海外试点仍需用目标用户反馈和通用模型基线做准确度、语气保持率、修改率和成本对比。

免费账号可用记录、练习、基础统计和示例归因；完整归因、趋势、提醒及 AI 分析属于 Pro。AI 还要求已配置服务且达到样本要求。供应商需要兼容当前客户端发送的 `reasoning_effort` 参数，不能假定不支持时会忽略。

缓存依据记录内容版本、账号、语言、模型以及当前本地日期生成指纹；旧的按天数缓存自动失效。趋势数字与文案来自同一规则计算，模型不能覆盖趋势文本。归因证据默认折叠，规则场景提醒并入对应卡片；AI 总结、重点解释和生成提醒单独展示，生成提醒不按数组下标覆盖规则提醒。

AI 缓存按账号保存。新增、编辑、删除记录会在同一数据库事务中清理该账号的旧摘要，清空记录也会清理该账号缓存。记录版本检查会拒绝保存分析期间已被修改或删除的数据所生成的摘要。缓存有效期为 24 小时，读取只查询并检查有效期，不做写入清理。服务启动后及每小时按过期索引删除过期或无效时间行；即使尚未清理，过期缓存也不会返回。

实际模型调用默认每账号同时 1 个，两次开始至少间隔 60 秒，全进程最多同时 4 个；强制重算也遵守限制。命中有效缓存不消耗调用名额。超限返回 429 和 `Retry-After`；模型报错仍计入冷却时间。

升级会自动清除无法识别账号归属的旧版 AI 缓存，保留原始记录和账号。这是数据库缓存清理，不会处理此前导出的文件、服务器备份或外部模型服务保存的数据。

生成兑换码：

```sh
cd backend
python -m app.codes 10
python -m app.codes --list
```

兑换额度检查、使用次数扣减和账号升级在同一个写事务内完成，限制并发请求重复消耗一次性兑换码。

## 隐私与登录保护

数据保存在部署服务器上的明文 SQLite 数据库，按账号隔离，非端到端加密。拥有服务器或数据库权限的管理员可能访问记录；导出文件需要自行保管。HTTPS 部署时传输加密。网站不会因为存在账号体系就自动获得数据库加密。

危机资源（`GET /api/crisis`）按地区给出可执行号码或官方查询入口，每条都带来源与核对日期（接口返回 `verified_at`、`source`，界面显示核对日期）。清单、来源与复核规则见 [危机资源](docs/crisis-resources.md)，测试会检查"每条资源可拨号或有链接、每个地区有 https 来源、中英文文案齐全"这三条不变式。

密码使用 scrypt 哈希，新密码要求 8—128 个字符，拒绝常见弱口令、重复单字符和用户名。旧的短密码仍可登录，以免升级锁出用户；修改密码后其他会话失效。修改界面带确认框和长度提示。

登录和旧密码验证按账号及客户端 IP 限速：5 分钟内账号最多 5 次失败，IP 最多 20 次；达到上限后返回 429 和 Retry-After。限速状态保存在单进程内存中，重启会清零。多进程部署应在网关增加共享限速。没有自助找回密码；界面提供联系管理员说明。

注册默认每 IP 每 5 分钟最多 10 次尝试、全进程每分钟 40 次，在密码哈希前检查。不存在的用户名也执行密码校验计算；这减少登录计算路径差异，不保证完全消除所有时序差异，注册重名仍返回冲突。

退出登录只有收到服务器成功响应后才刷新页面。失败或超时会提示会话可能仍有效，并允许重新点击退出；不会把网络失败显示成退出成功。

## HTTPS 与反向代理

项目当前不附带 Nginx 部署模板。部署时需自行配置域名、证书和反向代理，并设置 Python 服务的进程环境变量 `TETHER_TRUSTED_PROXIES=127.0.0.1`（按照实际代理地址调整）。代理必须覆盖 `X-Real-IP`、`X-Forwarded-Proto`；不信任普通客户端自报的头。仅可信 HTTPS 代理下发 Secure Cookie 和 HSTS。AI 请求可能持续数分钟，代理读取超时应配合前端的 5 分钟等待上限设置。

Python 提供 CSP、X-Content-Type-Options、X-Frame-Options、Referrer-Policy 和 Permissions-Policy，文本响应使用 UTF-8。页面脚本全部外置，匹配 CSP。未知 API 返回 JSON 404，未知静态路径返回 HTML 404；API 响应禁止缓存。

静态文本支持 gzip、按编码区分的 ETag、Last-Modified、条件请求 304 和 HEAD；保留 `Vary: Accept-Encoding`。API 始终 `no-store`。连接默认空闲/读取超时 65 秒（须长于浏览器复用空闲连接的窗口）、最多 64 个活动连接线程，满载返回 503。超限请求体返回 413 并关闭连接；对已发送的上传最多额外排空 8 MiB + 64 KiB、等待 1 秒，任意大小或极慢上传仍可能断连，公网入口应配合代理的请求体与连接限制。

以下参数应设在服务进程环境中；`.env` 在读取 AI 配置时才惰性加载，不能依赖它配置启动阶段的 HTTP/data 设置：

| 参数 | 默认值 | 范围 / 含义 |
|---|---|---|
| `TETHER_HTTP_TIMEOUT` | 65 | 1—300 秒，socket 空闲/读取超时，不是整个 AI 调用总时限；低于浏览器复用空闲连接的时间会在客户端正要复用连接时把它踢掉 || `TETHER_HTTP_MAX_CONNECTIONS` | 64 | 1—512，活动连接线程上限 |
| `TETHER_AI_MIN_INTERVAL` | 60 | 1—3600 秒，每账号模型调用开始间隔 |
| `TETHER_AI_MAX_CONCURRENT` | 4 | 1—64，全进程同时分析数 |
| `TETHER_REGISTER_LIMIT` | 10 | 1—100，每 IP 每 5 分钟注册尝试上限 |
| `TETHER_ALLOWED_ORIGINS` | 空 | 逗号分隔的跨源白名单，逐字匹配、不支持通配；`http(s)` 的 127.0.0.1 / localhost 默认放行。同源部署不需要设置 |

这些限制保存在单进程内存中，重启清零；多进程或多实例需在代理/网关配置共享限流。原生 HTTP 服务仍建议放在 HTTPS 反向代理后使用。

**同源部署不需要配置跨源**：浏览器直接访问站点、或 Nginx 同域反代时，页面与接口同源，CORS 不参与；`TETHER_ALLOWED_ORIGINS` 只在原生壳（`capacitor://`）或独立调试前端这类真正跨源的场景才需要。

部署到服务器测试的最小改动：服务进程设 `HOST=0.0.0.0`（默认只听回环），端口按需；如需域名与 HTTPS，再按上面的反向代理说明配置。到服务器访问的方式（域名、IP、子路径）与本地完全一致，不需要改前端代码。

挂到 `/qienty/` 时访问地址必须带尾部 `/`，Nginx 使用带尾部 `/` 的 proxy_pass 去掉前缀。前端及 service worker 均按当前部署前缀工作。

应用代码不会自动启用 HTTPS，需由部署环境配置证书和代理。

## 手机端（最终形态）与 PWA

产品最终形态是手机应用，浏览器只用于开发和演示：界面按 390px 单列手机视口设计，桌面宽度下也保持同一条手机版心。当前已是可安装的 PWA——装到主屏后没有地址栏、断网能打开外壳。完整说明、真机验收清单和走向原生安装包的改造要点见 [手机端](docs/mobile.md)；排期、验收标准与待拍板事项见 [下一步计划书](docs/mobile-app-plan.md)。

已处理的手机端细节：刘海与手势条避让（`--safe-top` / `--safe-bottom`）、软键盘弹出时布局收缩（`interactive-widget=resizes-content`）、输入框统一 16px（iOS 不放大页面）、主操作 44px 触控目标、去掉点击灰块与 300ms 延迟、状态栏颜色跟随主题、「我的」页内置「添加到主屏」入口（Android 调系统安装框，iOS 给 Safari 操作说明）。

品牌标识采用「心形 + 情绪流线 + 光点」，沿用柔和墨绿、暖白与浅金配色。登录页、顶部导航和浏览器图标统一引用 `frontend/icon.svg`，清单使用同源生成的 192/512 PNG 图标与 180 像素 Apple 图标。

修改 SVG 后运行 `node scripts/generate-icons.cjs` 同步生成五种 PNG（含两种 maskable）。此开发工具需要 `sharp`，也可通过 `SHARP_MODULE` 指定已有包路径；应用运行仍不依赖第三方包。满幅图标用不透明底色，供系统套用自己的裁切；`icon-maskable-*.png` 把设计缩到 76% 居中在品牌底色上，避免 Android 主屏按圆形/方形裁剪时切掉心形与流线边缘。

Python 提供 `sw.js` 时自动将前端资产内容 hash 注入缓存版本。静态壳使用网络优先、离线兜底；API 不进入 service worker 缓存。若额外使用独立静态服务器，需等价实现 hash 注入，不能直接绕过 Python 托管。

资产版本缓存依据完整的相对路径、大小及纳秒修改时间清单失效，覆盖修改、增加、删除和改名；内容 hash 仅在清单变化后重算。发布工具不要同时保留被修改文件的原大小和原修改时间。预缓存任何壳资源失败会拒绝新 worker 的安装，旧 worker 不会因此被替换并清缓存。

## 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/bootstrap` | 200 返回登录状态；已登录时包含元数据、账号、首页记录 |
| GET | `/api/home` | 14 天关注记录或最近记录 |
| GET/POST/DELETE | `/api/entries` | 游标或 offset 分页 / 保存记录 / 清空当前账号情绪记录 |
| GET/PATCH/DELETE | `/api/entries/{id}` | 读取、补全、删除单条 |
| GET | `/api/stats/basic`、`/api/insights` | 固定 14 天的统计与缓存；days 若传只能为 14 |
| GET | `/api/weekly-card` | 最近 7 天可核对的记录与练习前后评分，并带前一周对照 |
| POST | `/api/expression/translate` | 主动改写草稿或按场景写一条可发送的消息 |
| POST | `/api/expression/interpret` | 解读对方发来的一句：字面、语气、潜台词与可选回复 |
| POST | `/api/insights/analyze` | 手动 AI 分析，body 可传 force |
| POST | `/api/import` | JSON entries 数组，原子追加并去重 |
| GET | `/api/export?format=json或csv` | 全量导出，CSV 文本带公式注入防护 |
| POST | `/api/demo/seed` | 仅追加，拒绝 reset=true |
| POST | `/api/auth/register或login或logout或password` | 账号与会话；网页用 HttpOnly Cookie，原生壳用 Bearer token |
| GET | `/api/auth/me` | 未登录返回 logged_in=false，不制造首屏 401 |
| GET | `/api/meta`、`/api/crisis` | 公开元数据与危机资源 |
| GET | `/api/health` | 公开健康检查 |
| GET | `/api/interventions/{emotion}` | 情绪短引导内容 |
| POST | `/api/entries/{id}/intervention` | 更新记录的引导结果 |
| GET | `/api/practices` | 练习目录 |
| GET/POST | `/api/practice-sessions` | 练习历史 / 幂等开始 |
| GET/PATCH/DELETE | `/api/practice-sessions/{id}` | 练习详情 / 按版本保存 / 删除 |
| GET | `/api/practice-summary`、`/api/practice-export` | 练习汇总 / 独立 JSON 导出 |
| GET | `/api/account` | 当前账号与权限 |
| POST | `/api/account/redeem` | 兑换 Pro 码 |
| PATCH | `/api/account/settings` | 账号语言、地区设置 |
| GET/PUT | `/api/wheel` | 读取 / 原子替换转盘清单 |

`POST /api/entries` 必须传 `tz_offset`（东正西负，整数分钟，-840 至 840）；occurred_at 若传必须带时区。cause 最多 500 字，note 最多 1000 字，severity 为 1—5 整数。可传 client_id 让同一账号的保存重试幂等。

列表支持 emotion、sort=severity或time、unfilled、older、q、days、limit（1—100）、cursor。前端统一传 tz_offset 以确定本地日期。查询校验失败返回 400；记录接口始终按账号隔离。

导入的 `entries` 每条必须包含有效 `emotion`、带时区的 `occurred_at` 及整数分钟 `tz_offset`，其他可选字段沿用记录保存约束。去重比较发生时间、情绪、强度、原因、备注、时区、引导完成状态和反馈；原始 ID 不作为导入身份。整批事务保留数据版本与缓存失效触发器，也过滤同一文件内的重复行。

## 验证

```sh
python -m unittest discover -s tests -v
```

`tests/test_regressions.py` 使用临时数据库，覆盖兑换并发与事务回滚、缓存账号隔离和清理、分析期间删除记录、旧缓存迁移、保存幂等、跨账号记录隔离、JSON 导入导出和登录会话。测试不读取真实业务数据库，不调用模型服务。

前端纯逻辑测试需要 Node.js：

```sh
node tests/run_frontend.mjs
```

`tests/run_frontend.mjs` 使用 Node.js 内置模块和隔离的 API/DOM stub，覆盖请求超时与取消、前后台刷新、旧响应隔离、退出重试、草稿重试与双语键一致性。不需要安装 npm 依赖；这些检查不等同于真实浏览器视觉及交互验收。

`tests/test_review_fixes.py` 补充真实 HTTP 的 gzip/304/HEAD、超限上传、并发与超时，及 AI/注册限流、只读缓存、导入、分页、日期与 CSV 边界。`.github/workflows/checks.yml` 在 Windows/Linux、Python 3.10/3.13、Node 24 下配置上述检查；本地通过不等同于 CI 已在线运行。

真实浏览器检查统一使用隔离启动器，自动创建临时数据库、随机本地端口并禁用真实 AI。需要 Node、Playwright 和 Edge；本次使用 Playwright 1.62.1。可以把包安装到已有测试工具目录后设置 `PLAYWRIGHT_MODULE` 为其绝对模块路径，`EDGE_EXECUTABLE` 可指定浏览器路径；默认使用 Windows Edge。示例（项目不增加生产依赖）：

~~~powershell
npm install --prefix .cache/browser-tools --no-package-lock playwright@1.62.1
$env:PLAYWRIGHT_MODULE = (Resolve-Path '.cache/browser-tools/node_modules/playwright').Path
python -B tests/run_browser.py
# 单独重跑复核场景
python -B tests/run_browser.py review_browser.cjs
~~~

三组浏览器脚本覆盖表达、练习及本次修复，包括真实保存 401、资源返回、练习关联重试、减少动效及评分焦点。截图写入忽略目录 `.cache/ui-preview`。可选执行 `python -B tests/benchmark_review.py` 复测隔离导入和静态表示性能；耗时不是 CI 硬阈值。

手机端验收（产品最终形态在手机上，所以这一步不能省）。同样使用隔离启动器与真实浏览器引擎，在 5 个设备视口跑完整流程，量化检查横向溢出、触控目标、输入框字号、文字裁切、底部导航、浮层、装机条件与离线壳：
